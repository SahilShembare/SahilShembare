## 🚀 Featured Project

### 🍽️ SmartDine

**Intelligent QR Code Based Food Ordering Platform**

A digital food ordering system where customers can scan a table QR code, browse the menu, add items to cart and place orders.

**✨ Features**

📱 QR-based Table Ordering  
🍔 Digital Menu  
🛒 Shopping Cart  
👨‍🍳 Kitchen Order Management  
📊 Admin Dashboard  
🔥 Firebase & Firestore  
📲 Progressive Web App (PWA)
